# Air Hockey runtime art, 13 November 2026

This is an in-game art pass, not another catalogue banner. Four new raster masters are integrated into the table, title and result screens. The public hub release remains unchanged.

## Art produced

| Asset | Runtime size | Purpose |
|---|---:|---|
| Perforated navy table surface | 1794 × 876, 117,050 bytes | Restrained wave engraving; coral opponent end and cyan player end |
| Cyan mallet | 174 × 174, 25,566 bytes | Polished grip/base with six-coin engraving |
| Coral mallet | 174 × 174, 27,806 bytes | Matching opponent variant |
| Ivory puck | 90 × 90, 7,228 bytes | Clear white mass with a narrow gold edge |

Total runtime artwork: **177,650 bytes**. [PNG masters and exact prompts](../assets/source/art-20261113.json), [export/source hashes](../assets/asset-manifest.json), [provenance](../assets/CREDITS.md). Generated with the built-in image tool; the coral master is an edit of the cyan master. Masters are flattened PNGs, not layered files, and remain outside the shipping public folder.

The larger mallet masters are also used at title/result-screen display size. Native metal rails, goal wells, markings and a restrained centre stamp complete the same material treatment. The scoreboard is kept above the playable field.

## Geometry and loading

- No rules, physics, AI, input or save changes.
- The surface is drawn exactly within x40–920 and y70–500. Goal mouths and marked edges use the existing simulation constants.
- Mallets display at58px including2px transparent padding on each side, matching the existing radius27 disc. Puck displays at30px including2px padding, matching radius13.
- Sprite centres remain(0.5,0.5). No external glow or shadow changes their apparent collision footprint.
- Boot loads four relative WebP paths. Missing images retain the original procedural textures and dark table surface.
- Source and export hashes, alpha and normalisation settings are recorded. The preparation uses alpha trimming and size/padding normalisation, not hand-edited backgrounds.
