# Game Stage Gate

Use this evidence sheet before promoting a project. A stage reflects what runs today, not intended scope.

| Stage | Definition | Required evidence |
|---|---|---|
| 1 — Started | Repo and project contract exist; no complete loop yet. | Build starts; brief and controls exist. |
| 2 — Playable Core | A player can start, act, fail or succeed, and restart. | Smoke-path result and playtest report. |
| 3 — MVP | A stranger can play unaided; pause, save/mute policy, and target-device story are settled. | Human playtest, screenshots, device coverage, open-issue disposition. |
| 4 — Polished | Art, audio, feel, performance, and accessibility pass are deliberate. | Stage-3 evidence plus release playtest report. |
| 5 — Flagship | Content-complete, publicly positioned, and maintained as a flagship. | Launch/distribution plan and post-launch ownership. |
